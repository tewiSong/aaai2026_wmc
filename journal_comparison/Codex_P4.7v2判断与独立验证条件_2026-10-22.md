# P4.7 v2 判断与独立验证条件

核查：阅读 `p4_7v2_c2_exact_vs_logodds_bp.py`、稳定 BP 实现和四组结果 JSON。固定 theta* 的 100 蛋白结果与此前独立复算一致；此次没有重新训练整套模型。

**判断：支持推进独立确认。被测 log-odds BP 在当前 C2 管线中仍明显不如精确推理；矩匹配参考模型是当前设计的重要组成部分。不能把收益单独归于 theta*，也不能将去掉矩匹配解释为同一模型只换了优化初值。**

## 1. theta* 是固定参考项，不只是优化初值

训练和预测使用的都是 `theta = TH[k] + w0 + w1*L + w2*M`。TH 在学习后仍被保留。

- TH=theta* 时，模型包含按整个分数向量和本体结构反解的参考势函数。
- TH=logit(目标) 时，这个参考项可与同一节点的 M 特征合并，换成了更受限的参数映射。

因此两种“起点”实际对应不同的模型参数族；其比较支持固定参考模型／参数映射的重要性，不是优化器初始化好坏的单独证明。

theta* 在不学习残差时只复现平滑保序边缘，所以它单独不能解释相对于保序回归的提高。最稳妥的解释是“矩匹配参考模型、残差学习及相应的可靠推理共同产生收益”。

## 2. BP 结论的范围

新实现修复了此前消息概率域的伪收敛问题；本轮两种参考项、两种推理引擎的比较更完整，保存的指标支持其报告的性能模式。

但“被测 BP 矩匹配和训练失败”仍不等于所有 BP 配置或其他近似推理失败。去掉矩匹配并未测量矩匹配所需的最低精度；若要证明精度阈值，可另做目标残差／推理误差扫描。该扫描不是启动独立确认的前置条件。

当前支持准确矩匹配有价值，不支持“必须机器精度精确”“只能 WMC 求解器实现”或“原稿模块／低秩方法已经必要”。后者必须在 GO bp 的新任务上实际验证。

## 3. 独立确认可以开始，以下条件应先冻结

1. **时间和样本定义**：固定信息截止 t0 与评估快照 t1；用两个历史注释快照比较新增实验注释，按命名空间区分先前无实验注释和先前已有注释的任务。不能仅用当前条目更新时间来判断“新获实验注释”。2021-11 是候选截止点，需要说明与 CNN 模型、校准标签、同源参考库的时间关系。
2. **独立性**：独立确认集合与 CNN 训练／验证集及 C2 校准集核查 ID 和相同序列；去重规则预先固定。若允许某类先前已知蛋白，应明确其任务身份，不把它称为完全未见的新蛋白。
3. **冻结输入信息**：使用发布的固定 DeepGOPlus 1.0.6 权重和仅含其旧训练数据的 DIAMOND 参考库／注释。新快照用于生成评估标签，不能反馈到同源转移分数中。
4. **公平拟合**：3,874 是旧包蛋白总数，不能默认每个命名空间都有标签。保持明确的命名空间筛选，不把缺失注释直接当作可靠阴性；目前 cc/mf 的有效蛋白分别约 2,912/2,129。C2 与全部校准、PCA 等对照都应使用同一可用拟合集重拟合。
5. **固定评价空间**：明确本体快照、预测头词表、根处理、别名映射、新术语的处理及覆盖率。新数据中哪些样本被排除及原因必须报告。
6. **推理环境复现**：新 TensorFlow 容器先在旧样本上复现已发布 CNN 分数和融合分数，再处理新样本；锁定发布权重校验和与推理参数。
7. **锁定确认规则**：方法、正则化、训练停止准则、主要指标与配对统计在查看新集合性能之前固定。可以预先报告 Fmax，但不能根据新集挑选模型、训练步数、PCA 维数或正则化。四组设置和已知例外都需报告。

这是一个独立的回顾性时间留出确认。若声称与 CAFA 完全相同，还要满足其时间延迟任务定义；严格的前瞻挑战意味着预测先于未来标签提交，不能混用措辞。

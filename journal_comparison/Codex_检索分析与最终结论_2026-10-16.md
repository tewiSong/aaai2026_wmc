## 1. 当前结论及明确撤回的判断

1. **AIJ 收过相关方向。** WMC 概率推理、WMI 的结构利用与可扩展算法、本体中的概率推理均有已发表实例。没有依据用“方向不适合 AIJ”排除本稿。
2. **本稿的主线可以保留，并以 AIJ 为大修目标。** 这是一项利用模块结构和紧凑联合边界表示，实现大型本体条件概率推理的方法研究。没有理由先规定必须另造一个基础算法，才有 AIJ 投稿资格。
3. **尚不能确认创新和验证已达到 AIJ 的竞争要求。** 当前材料不能完成强方法对照、大规模最终概率精度和宽边界全部边缘恢复的核实。
4. **也不能确认充分扩展后的创新仍不及已发表 AIJ 论文。** 已有构件各自有前史，不推出具体组合没有方法创新；现稿的两个命题理论增量较小，也不推出整体计算方法必然不够。
5. **IJAR 是较保守的投稿策略，JAIR 是另一可争取目标；两者都不是已经证明 AIJ 创新不够之后的必然归宿。** 本次有意选择的少量样本不能建立三个刊物的机械难度排序。

Codex 在前期讨论中曾从“补充路线有前史、现稿证据不足”，推成“充分扩展后仍创新不足，必须实质升级研究主线”；该判断超出了证据，撤回。随后直接回答“够作为 AIJ 方法贡献”也偏肯定：可以争取是投稿策略判断，已经足够则需要目前尚未取得的证据。本文保留前者，不把后者当作已证实结论。

## 4. 本文究竟贡献什么

### 4.1 任务与语义

预测器给每个术语一个 Bernoulli 分数，形成乘积参考分布。将该分布条件化在 Boolean theory T 上，以一个统一 normalizer 得到满足约束的联合后验，并计算全部术语的边缘概率。

需要分开 ontology DAG、其编码出的 Boolean theory T，以及用于分解和宽度分析的无向 primal graph。当前主要实验编码的是 child ⇒ parent 的术语蕴含约束，不能据此宣称处理完整 OWL/DL 语义。

### 4.2 创新定位

建议将主要贡献表述为：

> 利用本体的模块结构，通过从条件 WMC 查询构建、单独处理逻辑支持的紧凑联合边界表示，结合递归 core 推理与全部术语后验恢复，将条件 WMC 推理扩展到完整的大规模本体。

“WMC scale 到 GO、ChEBI 等大本体”确实是研究主线和计算能力目标。支撑这个目标的技术内容是具体的边界构建、表示、组合与恢复机制。原稿报告上至 ChEBI 205,592 个术语的完成结果；这是作者报告，尚非本次独立复现。

| 内容 | 本次判断 |
|---|---|
| WMC 定义、条件化概率语义 | 已有基础，不是本文首创 |
| 模块消元、用联合 separator 保持依赖 | 有 compositional WMC / VE 前史 |
| 从 boundary-clamped WMC 查询直接构建宽边界非负 TT，并分开逻辑支持 | 主要应检验的具体方法增量之一；需与 TT-cross、tensor inference/compilation 逐项比较 |
| TT 进入 reduced-core 推理、递归处理与全部边缘恢复 | 可能形成有价值的整体算法贡献；实际计算过程和总成本必须明确 |
| 精确等价性及 TV 收缩 | 正确性基础，不宜独自承担主要创新 |
| 完整大型本体上的可计算性 | 若同任务、同预算、精度可核实地成立，可成为重要方法结果 |

本次没有查实与上述整套组合完全相同的 AIJ 论文；也未完成足以支持“世界首次”的穷尽性检索。未找到相同工作和已证明首创是两件事。

## 5. 实际与哪四篇 AIJ 全文比较

### A3：Spallitta et al. (2024)，最适合比较贡献形式

*Enhancing SMT-based Weighted Model Integration by Structure Awareness*，AIJ 328，104067。[DOI](https://doi.org/10.1016/j.artint.2024.104067)；[本地全文](papers/AIJ/2024_Spallitta_Structure_Aware_WMI_arxiv.pdf)。下载的是 60 页作者稿，正式刊版物理页数未核实。

该文先定位 WMI-PA 忽略权重函数条件结构造成的冗余枚举，以及部分 KC 方法在耦合问题上的代价，再用 conditional skeleton 引导 SMT 枚举。第 4 节分析瓶颈，第 5 节建立机制，第 6 节做合成与真实数据实验，第 7 节扩展精确/近似积分并检查最终结果。

它与本文的相似之处是：通过具体结构利用和算法设计，扩大一个概率推理框架的实际可计算范围。它没有要求从头创造 SMT、枚举或积分。本文应相应说明模块划分、宽边界构建与 TT 推理分别解除什么瓶颈，以及收益为何来自这些机制。

**比较结论：** 这是本文最有用的方法论文参照，不是同一任务的直接速度基线。现稿的瓶颈论证、强方法对照与最终误差证据弱于该文已经展示的论证；这不等于本文充分扩展后整体创新必然较低。

### A2：Abboud, Ceylan & Dimitrov (2022)，近似理论路线

*Approximate Weighted Model Integration on DNF Structures*，AIJ 311，103753。[DOI](https://doi.org/10.1016/j.artint.2022.103753)；[本地全文](papers/AIJ/2022_Abboud_Approximate_WMI_DNF.pdf)。出版社版 25 页。

该文在指定权重及 oracle 条件下建立 DNF-WMI 的多项式随机近似结果，区分强/弱 oracle、适用条件与精度保证，并做规模实验。

**比较结论：** 本稿目前的两个命题在理论增量上弱于这种可近似性结果。但本文可以走结构化算法与实际可扩展性的路线；不能把该文的 FPRAS 当成每篇 AIJ 方法论文的统一要求，更不能直接拿 WMI 变量数与本体术语数比较贡献高低。

### A4：Malhotra, Bizzaro & Serafini (2025)，可处理逻辑扩展路线

*Lifted Inference beyond First-Order Logic*，AIJ 342，104310。[DOI](https://doi.org/10.1016/j.artint.2025.104310)；[本地全文](papers/AIJ/2025_Malhotra_Lifted_Inference_arxiv.pdf)。正式刊版 29 页，下载作者稿 55 页。

该文通过 counting by splitting，将 C2 的 domain-liftability 扩展到包含指定无环、连通、树和森林约束的情形，提供新的可处理范围与组合计数应用。

**比较结论：** 这是明显的理论增量，不能用本文现有的消元恒等式与之等量齐观。但其关系逻辑任务、复杂度参数和本文不同；它不构成“本文必须证明同类新逻辑片段才够 AIJ”的证据。

### A1：Chavira & Darwiche (2008)，基础定位与结构利用

*On Probabilistic Inference by Weighted Model Counting*，AIJ 172(6–7)，772–799。[DOI](https://doi.org/10.1016/j.artint.2007.11.002)；[本地全文](papers/AIJ/2008_Chavira_Probabilistic_Inference_WMC_author.pdf)。正式刊版 28 页，下载作者稿 48 页。

该文沿 Bayesian network 到 CNF 的编码、搜索与编译、局部结构三个维度整理并补充结果，展示 WMC 如何利用确定性等结构扩展精确推理的范围。

**比较结论：** 它说明高 treewidth 不等于所有 WMC 方法都困难，编译复用和逻辑结构利用也不是新概念。它主要用于校准本文与已有基础的关系，不是同年代同类型的新颖性门槛，不能要求本文重新提出 WMC 框架。

### 只作方向或摘要核查的其他 AIJ 来源

- Lukasiewicz (2008)，[*Expressive probabilistic description logics*](https://doi.org/10.1016/j.artint.2007.10.017)：核查出版记录与摘要，明确涉及 Semantic Web 本体中的概率推理。未做与上述四篇同等深度的全文比较，未下载到这组本地 AIJ 样本。
- Gogate & Dechter (2011)，[*SampleSearch: Importance sampling in presence of determinism*](https://doi.org/10.1016/j.artint.2010.10.009)：核查摘要与出版记录，方法结合采样和约束回溯搜索，并分析相应权重。它支持“已有技术的有实质作用的新结合可以成为方法贡献”的判断，不是本文性能或整体创新的直接比较结果。

因此，“AIJ 没收过这个方向”不成立；“本文必定不如这些论文”也没有在本次工作中得到证明。

## 6. JAIR、IJAR 样本及篇幅、写作、逻辑比较

其余 5 篇全文和 DOI 见 [论文导航](论文清单与阅读导航.md)：

| 样本 | 对本文的具体用途 |
|---|---|
| JAIR / Li et al. 2011，37 页，*Exploiting Structure in Weighted Model Counting Approaches to Probabilistic Inference* | 专门结构上的编码和算法进展可以成为方法贡献；比较能利用相同结构的强对手 |
| JAIR / Oztok & Darwiche 2018，32 页，*An Exhaustive DPLL Algorithm for Model Counting* | 定义新算法与表示关系，分别评价计数和编译；不要求每项速度都领先 |
| JAIR / Bryant et al. 2025，43 页，*Certified Knowledge Compilation with Application to Formally Verified Model Counting* | 区分形式化工具链的验证范围与简单恒等式验证；后者不能代替系统端到端认证 |
| IJAR / Dal & Lucas 2017，22 页，*Weighted Positive Binary Decision Diagrams for Exact Probabilistic Inference* | 比较新表示、编译和查询成本；IJAR 同样要求明确技术增量 |
| IJAR / Dal et al. 2021，29 页，*A Compositional Approach to Probabilistic Knowledge Compilation* | 直接技术近邻：exact compositional inference，需逐项比较分区、context、边界通信与查询 |

**篇幅：** 本组 JAIR 样本为单栏 32–43 页；若用刊版计数，已核实的 AIJ 样本为 25–29 页，作者稿可能长得多。它们不是最低篇幅要求，也不足以推断期刊平均篇幅。Claude 的“JAIR 双栏 25–50 页”不能用作规划依据。

**写作：** 应先让读者理解固定预测器分数、约束后验、全部边缘查询与现有方法的瓶颈，再介绍分解和 TT。不要让 diamond 示例或符号解释承担主体贡献，也不要把给审稿人的回复措辞留在新稿正文。

**逻辑：** 有效论证应连接同一条计算链：任务与基线瓶颈 → 新机制 → 可执行恢复与成本 → 最终概率质量 → 时间、内存和规模。小图 exact、完整本体 completion、另一个 exact 设置的下游结果，不能自动拼成这条证据链。

**创新：** 应比较新机制带来的能力与代价，而不是按是否含新定理、变量总数或刊物名称打分。现稿理论部分较弱与整体方法没有价值不是同一结论。

## 7. Claude 与 ChatGPT 的判断是否一致

两者对写作重构、强 WMC 对照、大规模精度验证不足的判断基本一致。Claude 明确偏向 JAIR，并给出修改计划；用户提供的 ChatGPT 对 AIJ 持有条件的积极判断，强调题目适合但现有计算创新与证据需要核实。

ChatGPT 强调最终后验误差，比把跨 rank 一致性作为主要精度验证更准确。Claude 的计划有参考价值，但其改稿不能作为研究已完成的证明。本次发现的主要问题如下，详细数值和原稿对照见 [前期核查第 5 节](投稿判断与AI建议核查.md#5-claude-文件中的具体问题)。

- 新跨 rank marginal MAE 表中的 8 个数，逐项等于原稿旧 separator 表的 TT-2/TT-4 held-out NMAE 中位数，指标被换名；rank-16 新数值没有在提供材料中找到来源。
- 新增 ADDMC、DPMC、d4 的 OOM/timeout 声称没有相应运行记录，不能当成已核实结果。这不是已证明作者从未运行，而是当前证据不足。
- 把 Dal 2021 写成通过独立乘积近似通信，与其 exact compositional inference 定位不符。
- 把 core selector 写成 weight-aware；原稿所给排序依据是图上的 degree、父节点数和 id，未见对应权重驱动机制。
- 跨 rank 变化小不是真值误差上界；2000 Boolean 变量的普通穷举不能作为通用 reference；给对手 30 分钟却将本法 9.7 小时完成记为优势，预算不匹配。
- “最低 ECE”的改写遗漏原文限定；Raw 的 ECE 实际更低。下游采用 exact GO-CC，不能直接证明大规模 TT 推理效果。

用户提供的 ChatGPT 建议也不等于已经证实 AIJ 创新足够；其原意正是有条件的判断。

## 8. 审稿问题中应保留与修正的部分

**应保留：** 大规模精度、强基线、宽边界恢复的可执行性及贡献边界，是重要问题。局部 factor 拟合误差与全图最终边缘误差不可互换。全部边缘推理与单次 Z 查询也必须在公平任务定义下比较。

**应修正：** 不能说当前材料的所有精确验证都未启动分解。自动 GO-CC 配置确实 modules=1、depth=0，但补充另列 forced modular 配置；432 个参考子图写为 GO-MF、GO-BP、UBERON、ChEBI 各 108 个，不能全称作 GO-CC 子图。非平凡分解也不要求递归深度至少为 1。

**宽度需澄清：** 连通模块的内部变量消去而全部边界保留时，结构消元会产生边界 clique；这与将边界钳制后仅计算内部 oracle 的宽度不同。原表的 width 是 top-level，max boundary 可能跨层，因此不能凭主表直接宣布数学矛盾。应逐层报告模块、边界、两种宽度和 TT bond dimensions。

| 边界采样、精确模块回代及 importance correction | 推导校正和全部边缘估计，合成例中总体校正与真值差约 2.22e-16；有限样本仍有误差 | 有 cutset/Rao–Blackwellized sampling 与 TT sampling 前史；有限样本后验比值不无偏，未证明大图采样成本 |
| 对拟合 separator 的 normalizer 自动求导 | 构造值误差为零但导数给出 marginal 7/3、真值为 1/3 的反例 | 值拟合不能直接保证导数正确；不是否定保留概率多项式语义的正确 differential inference |
| 内部赋值类别与 cube 上下界 separator | 构造 lower joint、上下界 normalizer 及全查询误差证书；100 图、503 细化配置的枚举检查通过，最大恢复差约 5.55e-16 | 最坏类别数指数增长，初始界可能无信息；浮点验证不是外向舍入数值认证；证书不适用于任意原稿 ALS-TT |
| TT 排序反例 | 树结构、clamped 内部宽度为 1，16 维边界的一种顺序 exact rank 为 256，交错顺序为 3 | 小内部宽度与 DAG 不能给出与排序无关的常数 exact rank 保证；未否定特定误差下的低秩近似 |
| 1082 维边界解析例 | 两个 rank-one cube 即可解析收缩，无需显式边界表 | 证明宽边界紧凑恢复在某些结构上可行；例子本身是树，标准精确推理也容易，不能用来证明方法领先 |
| 局部拟合误差反例 | 因子 uniform NMAE 为 5e-9，特定 cavity 下后验绝对误差仍为 1/6 | 说明不能把局部拟合指标直接转换为最终精度；不是对真实 GO 数据误差的测量 |
| 均匀查询支持覆盖 | 对只有 k+1 个合法赋值的 k 位边界分析 5000 次查询的命中概率 | 说明采样方案需交代支持覆盖；没有宣称生产本体边界都具有这个形状 |

**新颖性判断的适用范围：** 找到这些路线的前史，只能阻止把某个直接补丁贸然宣称为首创，不能推出原稿整体组合没有创新，也不能证明充分完成后的贡献不够 AIJ。

## 10. 项目的当前定位与投稿决策

建议按“结构利用驱动的可扩展概率推理方法论文”继续完成：其主要工作负载是大型本体的蕴含约束，其主要结果应是有质量依据的全部术语后验推理。生物学数据提供重要任务，论文主体仍是推理算法。

AIJ 可以保留为大修后的目标。接下来真正决定贡献分量的是：现有具体机制相对 compositional WMC、tensor inference/compilation 和合适 Horn solver 的差异；同任务、同预算下的总成本；以及最终概率的可靠性。应报告正面结果与失败区域，而不预先假定所有现代 solver 都会 OOM。

这不是要求先另发明一个新研究方向。若现有机制已经带来实质新能力，实验能够确立原有方法贡献；若对照显示已有方法同样有效，则需要根据实际差异重新定位。当前还没有这组结果，不能把任一结局当作事实。

**最终记录：AIJ 收过相关方向；本次真正用于全文比较的是上述四篇 AIJ 论文；它们没有支持“本稿充分扩展后创新仍必然不足”的断言。保留现有研究主线争取 AIJ 是合理策略，创新是否已充分成立仍待具体技术比较和验证。**

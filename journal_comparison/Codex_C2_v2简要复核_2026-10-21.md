# C2 v2 简要复核

核对范围：稳定 log-partition 修复代码、P4.5/P4.6 v2 的结果 JSON、两个新增对照的代码。此次未重新训练或重算全部 v2 bootstrap；此前 v1 的完整重算见独立复核报告。

## 接受

- `Circuit.marginals_theta` 直接使用稳定的 log 字面量权重，修复了此前截断造成的目标／梯度不一致。现有 C2 的矩匹配和梯度都调用此接口。
- 保存的矩匹配最大误差依次为 1.545e-5、1.802e-5、1.980e-5、1.383e-5，符合“均小于 2e-5”。结果显著改善了 v1 的离群误差。
- 四组 C2 的点估计基本保留；对新增 theta* 特征和 PCA32 对照，保存的 Fmax 区间支持三组显著提高，cc CNN 不显著。继续 C2 的研究有依据。
- PCA 只在拟合半上求均值和主成分，没有发现 PCA 在评估半拟合的泄漏。

## 应收窄

1. **“三组显著胜过所有方法”须注明指标。** 对逐术语 Platt，mf CNN 的 micro AP 差值 95% 区间为 [-0.0000128722, 0.0162156]，包含零；Brier 和逐标签 log-loss 的区间也包含零。“三组 Fmax 显著优于已测对照”成立，不能改写为这些组全部指标均显著更好。
2. **未收敛不等于测试成绩偏低。** cc CNN 和 mf CNN 的优化器确实达到 300 步上限。继续优化可以降低训练目标，但测试 Fmax/AP 可能升、降或不变。不能把当前数字称为有保证的保守下界。
3. **新增消融加强了模型收益的证据，但未唯一识别机制。** theta* 特征模型只使用当前节点的 theta*，并非整个 theta* 向量；PCA 模型只保留 32 个主成分，而且同深度术语共享 PCA 系数，因此它仍是受限的全向量线性模型。不能从这两种具体对照的失败推出所有“更充分利用输入信息”的解释均被排除。
4. **概率推理需求不等于精确 WMC 不可替代。** 当前实现采用精确电路是事实；BP 替代结果、其他精确或近似后端、成本和预测效果比较仍未完成。即使 BP 变差，也尚未证明原稿模块／低秩算法能够有效改善当前任务。
5. **只验证了边缘预测指标。** 目前没有独立的联合概率或多证据条件查询评测，不能直接宣称联合后验本身更接近真实联合分布。

## 判断

支持保留 C2 候选主线，先完成收敛检查、BP 对照和新的锁定留出验证。现有探索结果足以支持下一阶段，但尚不足以确定收益唯一来自联合推理、精确求解不可替代，或已达到目标期刊的贡献要求。

原始证据：`experiments/scripts/learned_constrained.py`、`wmc_inference.py`、`p4_6_ablation_same_features_without_wmc.py`，以及 `experiments/results/p4_5_nested_C2_*.json`、`p4_6_ablation_*.json`（不含保留的 v1 文件）。

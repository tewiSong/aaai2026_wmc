# P4.4–P4.6：C2 设计、数值实现与收益归因的独立复核

日期：2026-10-21。只读 Claude 的代码、缓存和结果；新增审计脚本及结果，不修改其模型实现、缓存或正式实验文件。

**判断：支持继续 C2。它落实了“先反求保持边缘的参数，再学习残差”的合理设计；四组正面点估计能够复现。当前不能接受“消融已经确认收益来自联合建模”“精确 WMC 不可替代”或“原稿计算方法已有用途”作为完成的结论。首先应修复一个已复现的数值目标／梯度不一致问题，再重做矩匹配和拟合。**

## 1. C2 改了什么，理论上是否成立

先将原始分数做保序投影得到 ISO，再取

\[
m=(1-10^{-3})\,\mathrm{ISO}+10^{-3}\,m_{\rm uniform},
\]

其中第二项是合法状态均匀分布的边缘。理想的精确投影下，这使目标处于可实现边缘集合内部；当前数值投影也需检查容差。

对每个蛋白反求 theta0，使合法支持上的指数族边缘等于 m。随后学习

\[
\theta_i=\theta_{0,i}+w_{d,0}+w_{d,1}\operatorname{logit}(s_i)
                      +w_{d,2}\operatorname{logit}(m_i).
\]

这是有明确概率意义的结构化校准模型。原始分数是特征，theta 是势参数；不再直接混淆边缘与势参数。理想的精确矩匹配下，零残差保持平滑后的目标边缘。新增的残差允许在该起点上利用标注学习，而不仅是逐蛋白复制目标。

但要分清：它理论上包含的是平滑目标，而不是原封不动的 ISO；当前数值实现又有反求误差。因此“w=0 与保序回归完全一样”应改成“理想情况下等于平滑目标，实际达到所报告的矩匹配精度”。嵌套也只给出模型可以选择零残差的性质，不保证测试集指标不下降。

C 的非嵌套和低 R² 支持其参数化受限，但未加权参数空间中的最小二乘 R² 不是最佳边缘拟合误差的下界。特别是接近边界时，反解参数可能很敏感。不能把一次参数回归的最大边缘误差 0.98，当作任何 C 参数都必然有如此误差的证明。非嵌套模型也可以公平比较；嵌套是有用的设计，不是所有对比实验的必备条件。

## 3. 必须先修的数值实现问题

`learned_constrained.py` 的 `log_partition` 先做

```
p = clip(sigmoid(theta), 1e-12, 1-1e-12)
A_reported = log_Z_Bernoulli(p) + sum(softplus(theta))
gradient_reported = marginals(p)
```

当 theta 被截断时，前一项使用的是截断后的模型，后一项仍使用原始 theta。目标不再是声明的 log 分区函数，返回的边缘也不再是这个数值目标的导数。

这不是假设性担忧。对两节点 C=>A、theta=(-40,40)：

- 真正的 log 分区函数约为 **0.693147**；当前实现给出 **13.062115**。
- 当前实现返回的梯度约为 **(.500006,.500006)**；对它实际返回的数值函数做有限差分，得到 **(0,1)**。
- 直接在 log 权重上稳定求值得到正确分区函数及边缘 **(.5,.5)**。

实际缓存也超出了截断范围：四组 theta0 最小值约 -34.2、-37.3、-37.7、-41.1；每组有 17–47 个蛋白包含超界参数。个别缓存参数上，该截断数值函数的导数与返回边缘差可达数十分之一。不能用普通参数范围下的自检或 L-BFGS 的 success 标志排除这个问题。

修复应直接使用稳定的 log 字面量权重：

\[
\log p=-\operatorname{softplus}(-\theta),\qquad
\log(1-p)=-\operatorname{softplus}(\theta).
\]

让电路接收这两个 log 权重求值，避免先算 sigmoid 再截断；或直接实现相应非归一化势的 log 空间电路。修改后需要包含极端相反参数的分区函数、边缘与梯度核对，并重新矩匹配及训练；仅重算最终预测不足以验证拟合是否改变。

目前固定已学参数，改用稳定求值后，四组 C2 的 Fmax/AP 优势大体保留：约 .66554/.61792、.70618/.69145、.50548/.45824、.70409/.68091。这说明错误没有自动抹掉正面信号；但不是重新正确拟合后的结果，不能据此宣布数值问题不影响最终结论。

## 4. 矩匹配只是近似完成

原保存结果全样本最大误差为 .1253、.0915、.0631、.0623；中位数约 1e-6，不能用中位数代替逐蛋白保证。

重算评估集的零残差预测，相对平滑目标最大误差分别约 .0972、.0711、.0631、.0623；误差超过 .01 的蛋白分别为 10、10、5、15 个。四组指标总体接近 ISO，不等于每个蛋白、每个术语都匹配。

稳定求值后仍存在矩匹配误差；因此既需要修正求值，也需要检查反求优化的终止、梯度范数与边缘残差。建议以预先规定的逐蛋白边缘残差作为成功判据，报告失败或回退，而不是只报告参数优化器终止。

## 5. 消融说明了什么，还没有说明什么

P4.6 比较的是：

- C2：逐蛋白 theta0 + 局部残差特征，经过结构化推理；
- 对照：自身原分数、自己的目标边缘及局部邻域特征，直接做 logistic 回归，再投影。

二者不拥有完全相同的中间信息：theta0 是利用整个边缘向量和本体结构反解的量，对照没有它。因此可以说“C2 完整管线优于已测试的局部 logistic 管线”，不能唯一归因于残差阶段的联合推理。Claude 自己提出的全分数向量基线仍然必要。

此外，C2 是在 theta0 上以零残差为正则中心；现有同特征 LR 的正则中心对应原分数，而非保序目标。C2 的似然损失先对术语求和再对蛋白平均；独立 LR 对该深度所有蛋白—术语对取平均，虽然 ridge 数字同为 1e-3，相对惩罚强度并不相同。

本审计新增：从目标边缘 logit 起步的同特征边缘残差，以及按每个深度术语数校正惩罚尺度的版本。匹配尺度版本的投影后点估计为：

| 模型 | GO cc CNN | GO cc 融合 | GO mf CNN | GO mf 融合 |
|---|---:|---:|---:|---:|
| 边缘残差 + 投影 | .66333 / .60321 | .69733 / .67173 | .49347 / .43677 | .68686 / .66224 |
| C2 | .66552 / .61791 | .70618 / .69153 | .50533 / .45814 | .70409 / .68090 |

C2 的点估计仍然更好。因此目前发现的正则化／起点差别不能单独解释掉收益。这是对正面信号的支持，不是对“精确推理是唯一原因”的证明。

两类模型的目标函数也不同。联合似然训练与边缘似然训练的差别本来就是模型设计的一部分；结果不能进一步解读为求解器精度带来了收益。

## 6. 论文结论与下一步

支持写成候选结果：“以一致边缘的矩匹配为起点，学习约束联合模型的残差，在当前探索集上改善边缘预测。”目前只检验了边缘指标，不能据此证明联合条件概率本身更准确。

优先顺序建议：

1. 修复第 3 节数值问题；重新矩匹配、拟合，并核对零残差精度和预测收益。先做小范围验证，再重跑四组。
2. 增加利用整个分数向量的非 WMC 对照，保留同起点和匹配正则化的局部对照；避免将不同信息量解释成单一机制的消融。
3. 比较精确推理与 BP 等近似推理的训练和最终效果，不能从 WMC 模型定义推导精确求解器不可替代。
4. 在新的锁定留出数据上确认；当前重复分析的探索集 bootstrap 不包含方法选择带来的不确定性。
5. 验证 GO bp 的实际成本和现有计算机制的增量贡献。旧 d4 崩溃是具体实现证据，原稿模块／低秩机制是否加速当前反求与学习任务仍需测量。
6. 在确定论文新意前核对已有 GO 概率协调和结构化概率输出工作。

停止 C 后宣布整类后处理无效过强；现在看到 C2 正面结果后立刻宣布“收益机制已经确认、原稿方法已经有必要性”同样过强。应保留有意义的新信号，先解决具体可复现的问题。

# P4.1b 复核、d4 崩溃检查与方向 D 判断

撰写：OpenAI Codex，2026-10-21，Europe/Helsinki。

**结论：这轮实验比上一轮规范，主要负面结果可靠。支持停止把“当前固定分数直接作独立 Bernoulli 权重再条件化”作为已经有效的预测改进方案；不支持将其扩大为“所有 WMC 蛋白后处理已被否定”“与求解精度无关已在六组全部证明”“D 的证据完整、投稿路线已经成立”。**

本次检查了新增输入构建、保序回归、下游评测、统计代码与日志。独立重算 cc/mf 四组主要指标和 1,000 次配对 Fmax 区间，检查独立精确参照；对 bp 核对输入、raw/max-closure 全量指标与 64 个样本上的保序求解，没有重跑全量 BP/Gibbs，也未启动新的研究方向。Claude 原有代码、结果和运行中的任务均未改动。

## 1. 实现是否正确

### 1.1 规范化输入：整体合理，抽查通过

`p4_1a_build_deepgoplus_v2_inputs.py` 做了以下有效修正：别名映射、唯一 replaced_by 映射、多预测头按预设最大值合并、CNN 与融合分开、标签在当前 is-a 理论上向上闭包、保存根节点索引。

对 105 个固定间隔选取的测试蛋白，独立用稀疏矩阵“归一化同源命中 × 训练标签”计算 DiamondScore，再构造融合分数。三个命名空间的 CNN 分数一致，融合差异不超过 5.4e-8，处于 float32 数值量级；所用 1,394 个同源主体都在训练集内。全部三个命名空间的标签层级违反均为 0。

这使当前词表内部的比较更可信。不过，该实验仍限于模型预测词表、当前 is-a 片段和一个发布包数据划分，并非完整 GO 或官方全部评测协议的复现。“规范化”不能用于扩大全部应用的结论范围。

### 1.2 保序回归：实际求解了所声称的 L2 投影

生产实验采用 `isotonic_dag_hildreth`，目标为

\[
\min_\mu \tfrac12\|\mu-p\|_2^2,
\qquad \mu_c\le\mu_p.
\]

源码中的逐边对偶更新、原变量更新与互补松弛停止检查一致，没有发现仅反复平均邻居而未解投影问题的错误。

另用独立随机种子生成 24 个小 DAG，与通用 SLSQP 约束优化器比较，最大差约 **5.4e-12**。cc/mf 全量输出的 Fmax、micro AP、Brier、ECE 与保存值一致。

数值细节：求解容差为 1e-9，而层级违反统计使用 1e-12，因此结果中的小比例“违反”主要是容差口径不同，不应解释为实际不一致。保序回归理论上产生的并列值可能被微小浮点差异拆开；对 cc/mf 输出分别舍入至 8 位和 6 位小数后检查，AP 最大变化约 2.9e-5，未改变本轮主要判断。以后可恢复活动约束上的并列块，或明确统一数值容差。

另一个细节是投影包含根节点，评价排除根节点。因此投影使完整向量的平方损失下降，并不保证排除根之后的 Brier 也逐组下降。mf/fused 的非根 Brier 微增不能据此判定求解器错误；本次确认四组完整向量 Brier 均下降。

自检代码打印了 Hildreth 与 SLSQP 的差异，却没有把该差异加入最终 assert，建议补齐。当前数值本身通过，不是已发现的结果错误。

### 1.3 推理、指标和配对统计：检查通过

cc/mf 四组的 raw、max-closure、isotonic、exact WMC 的主要点估计全部复现。新一轮独立变量消元核查的最大边缘差约 **5.7e-16**。

独立使用预计算阈值统计量重算 1,000 次配对 Fmax bootstrap，区间与 Claude 保存值最大差约 **2.2e-16**。没有发现把非配对结果当配对、差值符号颠倒或遗漏每次重算 Fmax 的问题。

micro AP 现在确实在每个并列组的末端求 precision，修复了上一轮问题。Brier、pooled ECE 按代码声明计算。不过 P4.1b 只对 Fmax 与 micro AP 保存 bootstrap 区间，不能把当前 Brier/ECE 的点估计变化也直接说成这轮已完成显著性检验。

## 2. 哪些结果已被确认

精确 WMC 相对 raw 的 Fmax 结果如下，点估计和区间均已独立复现：

| 命名空间 / 输入 | raw | exact WMC | 差值 | 配对 95% 区间 |
|---|---:|---:|---:|---|
| cc / CNN | 0.65830 | 0.64325 | −0.01505 | [−0.01712, −0.01224] |
| cc / fused | 0.69783 | 0.67546 | −0.02237 | [−0.02603, −0.01898] |
| mf / CNN | 0.49484 | 0.45902 | −0.03582 | [−0.04150, −0.03039] |
| mf / fused | 0.68120 | 0.62510 | −0.05610 | [−0.06202, −0.05163] |

因此，cc/mf 的负面结果相当稳健，已经不值得继续靠修补普通评测错误来解释。

保序回归与 max-closure 在这些配置上只产生小幅收益，部分区间跨 0。可以据此说“当前数据上，简单方法已提供比这一条件化模型更好的预测质量”。不能说所有一致性方法的收益都有一个千分位上限。

报告中的“Fmax 下降 0.012–0.062”混用了区间端点与点估计。四组精确方法的点估计下降范围为 0.01505–0.05610；六组 BP 的下降范围为 0.01569–0.05838。micro AP 的说法也应区分点估计与区间。

“ECE 约翻倍”只是粗略概括：四组精确方法约为原始的 1.61–2.48 倍；bp 两组 BP 约为 3.14 和 3.88 倍。

## 3. “六组条件化都被精确证明有害”不成立

bp 两组保存的是 BP 结果，没有精确 WMC：

- bp / CNN：raw 0.41329，BP 0.38508；
- bp / fused：raw 0.53926，BP 0.49404。

正确的分层表述应是：

> cc/mf 的四组精确条件化均显著降低 Fmax；bp 的两组 BP 近似后处理同样降低 Fmax。

不能用 cc/mf 上精确与 BP 的接近，自动保证 bp 上精确与 BP 的下游指标也接近。项目本身已经观察到 bp 的 BP 误差，因此更应保留这个限定；原 P1.4b 的统计参照还使用旧词表与旧输入，不能不经核对直接作为规范化新输入的误差界。

这不是说 bp 的精确结果大概率会翻转，而是当前尚无参照或误差传播界排除这种可能。

另外，当前脚本以 `n <= 1000` 决定是否做 exact，而非检查“对应理论是否已编译”。即使未来某个大理论编译完成，现脚本仍会跳过 exact。未来应匹配理论/词表哈希后显式使用相应电路，不能误用旧 4,474 项理论的电路来处理新 4,475 项输入。

## 4. d4 崩溃：事实正确，溢出有具体依据但未最终定位

日志确认：

- d4 子进程返回码 −11，符合 SIGSEGV；
- 顶层记录耗时 **32:56:11**；
- 子进程峰值 RSS **131.62 GiB**；
- 因异常被实验脚本捕获，顶层脚本退出码为 0。它表示失败被记录，并不表示 d4 编译成功。

需要纠正“内部计数约 2³²”的含义。日志中的

```text
c unitLits 4292870145 17171480580 Bytes
```

是保存单位字面量的数组容量，不是模型总数。源码 `DAG/DAG.hh` 使用 `unsigned int szUnitLits, capUnitLits`，以 `1<<20` 为块增加容量；`Branch.hh` 的索引为 `int`。

从日志所示容量出发，再增加两块，在 32 位无符号算术下会绕回 **1**。若继续按此容量 realloc 后写入旧位置，会存在明显越界风险。这比“恰好接近 2³²”有更具体的源码支撑。

但没有 core dump、调用栈或受控复现，仍不能认定这就是本次唯一崩溃原因。最准确的结论是：**该 d4 版本存在与日志吻合的 32 位缓冲区/索引风险，溢出是强候选原因。**

同意 Claude 区分“实现失败”和“问题不可解”。但仅据此也不宜概括所有 d4 版本的规模极限。后续至少需要更新版本或另一精确后端的核查，并保留完整 stdout/stderr，避免只留被截断的异常字符串。

P0.4 的 2^29.6 是给定分解下合法状态表的规模估算，不是已经实现的稀疏消元成本证明。索引、状态生成、连接和中间存储都可能增加代价，可以据它安排试验，不能预告另一后端一定能解。

## 5. 对“应用线已关闭”的判断

### 我同意停止当前具体方案的收益主张

在本次发布模型、数据划分、词表和权重解释下，直接把边缘分数当独立 Bernoulli 参数再条件化，确实没有提供预测收益。相较 max-closure 和保序回归，继续以“它改善标签预测”为卖点没有证据支撑。

cc/mf 的精确负面结果也说明，这些组的主要下降不能仅归因于近似求解。精确与 BP 下降量级相近，不等于两者数值完全一样，更不意味着所有命名空间都已证明与求解精度无关。

### 我不同意将其写成整个应用或整个工具的否定

“WMC 后处理”是一个计算工具与模型家族，不止当前固定一元权重方案。实验没有穷尽重新学习权重、经过独立验证的校准、其他联合模型、其他证据任务等情形。它们也没有被证明有用，但不能将未测试与被否定混为一谈。

三命名空间 × CNN/融合是六个设置，仍来自同一个发布包、同一 CNN 与相关的同源分数，并不是六个独立预测器或数据集。若 D 的论文主张是“对边缘预测器普遍有害”，独立架构或独立数据/划分就应是必要验证，而非可有可无。若不补，则应明确收窄为 DeepGOPlus 案例研究。

关于“重复计算证据”，上一轮已经给出正确边缘也会被改变的两节点例子。这足以说明模型失配可能性；真实数据中何种机制主导，仍需计划中的可控结构和分层分析。当前不能一边说机制实验待做，一边把机制归因称为证据完整。

## 6. 对方向 D：可以探索，但目前不是证据完备的稿件

D 中最有可能形成新实证价值的部分是：**把推理忠实度和预测质量分开，展示近似误差、求解成本和标签性能如何脱钩。** 它不需要预设所有条件化都无价值。

但“许多协调方法损害预测、保序回归较稳健”已有直接前史。Obozinski 2008 没有为现代预测器给出千分位收益定律，其结论随评价方式与置信区间而异，不能替当前结果的泛化背书。[原论文](https://link.springer.com/article/10.1186/gb-2008-9-s1-s6)

计算部分目前主要是 bag 状态画像、一个旧版 d4 的结果与 BP/Gibbs。它们是有用记录，但离“现代方法的大规模计算刻画”仍有距离。若大篇幅强调编译器崩溃，还需排除已知实现限制并比较任务相同的后端。

因此赞成把 D 当成有限预算的整理与研究方向；不同意“证据已经完整”“IJAR 或生信期刊已有充分把握”的判断。换期刊不能替代研究增量的建立。

## 7. 计划中“另一方向 KL”的文献对应有误

补看原文技术补充后，需要明确区分三件事：

1. §4.1 的 L2 保序回归 IR。
2. 同节边缘 KL：IR.2 为 Σ KL(p_hat||mu)，与 IR 同解；LO-IR 为 Σ KL(mu||p_hat)，可对 logit(p_hat) 做 L2 保序回归，再用 sigmoid 变回概率。
3. §4.2 的 KLP/KLPf 涉及受图因子化限制的**联合分布**投影及图方向变体，不是简单交换边缘 KL 的两个参数。

因此，Claude 对 L2 与前一方向边缘 KL 等价的说法正确；但“再补 Σ KL(mu||p_hat) 就补齐 Obozinski 的另一种 KLP”不正确。实现 LO-IR 是合理基线，却不等于重现 KLP/KLPf。

上述关系已经明确写在 [2008 技术补充 §4.1–4.2](https://media.springernature.com/original/springer-static/esm/art%3A10.1186%2Fgb-2008-9-s1-s6/MediaObjects/13059_2008_2052_MOESM1_ESM.pdf)。应先按原文定义修订对比清单，不宜依靠名称推测。

## 8. 我建议的下一步

1. 将当前结论改为“四组精确条件化负面＋两组 BP 负面”，保留相关模型和词表范围。
2. 不再投入大量重复的 cc/mf 同类验证，负面现象已经稳健。若选择 D，将资源用于至少一个独立预测器/划分、明确机制分析，以及与 2008 工作的具体差异。
3. 补 LO-IR 时使用正确公式；若声称比较 KLP/KLPf，则按联合模型定义实现或清楚说明不比较它们。
4. 计算部分区分理论难度、当前分解的表格成本、编译器实现限制及实际资源预算；崩溃不作为复杂度下界。
5. A 或 B′ 仍是尚未验证的选择，不能据现有结果给出可靠的“成功概率较低”排序。B′ 的难点不仅是计算，还包括合理联合模型与真正有信息的补全评测。

建议采用的研究结论：

> 在本研究的 DeepGOPlus 固定分数设置中，直接的乘积条件化不能改善蛋白功能预测；提高其推理精度也不能挽回 cc/mf 上的主要预测损失。简单边缘一致性方法更合适。这个发现提示应分别评估模型语义、推理误差和应用效果。

我赞成这个结论，不赞成“整个应用线已经结论性关闭、D 已可直接作为投稿方案”的扩大版本。

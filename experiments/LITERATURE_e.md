# (e) 文献核对：C2 主线与已有工作的差异（2026-10-23，Claude）

## 1. 后处理调和（reconciliation）：Obozinski et al. 2008（Genome Biology 9 Suppl 1:S6，PMC2447540）
- 比较了 11 种调和方法，作用在独立 SVM / 逻辑回归的输出上，覆盖 2,931 个 GO 术语，三个命名空间都有。
- **贝叶斯网络变体（BPAL / BPLR，沿用 Barutcuoglu 2006）**：
  - 模型：隐变量是每个术语的真实标签，观测是分类器输出，先验来自 GO 图。
  - 推理：**变分近似**，单次迭代 O(n)。
  - 结论原文为 "work consistently poorly"：按蛋白评估时多数输给保序回归，只在联合评估的高召回区间表现好。
- **保序回归**：三种评估模式下唯一一直排在前列的方法，"almost never performs worse"。
- **KL 投影**：只在联合评估的高精度区间最好。完整定义在补充文件里，未核实；若它是"向一致集合做 I-投影"，就等于我们的乘积条件化。
- **对我们的意义**：
  1. 历史上的联合模型输给保序回归，这与我们的 P4.1b 一致。
  2. 我们给出了原因：
     - 乘积条件化有系统性的深度偏差（单边恒等式，P4.2）；
     - 近似推理不够准（P4.7 v2，BP 做不到矩匹配）。
  3. 我们也给出了修复：矩匹配起点 + 精确推理 + 学到的残差（C2），在探索与独立时间划分上都胜过保序回归（P5）。

  这条"为什么联合模型过去输、现在怎样能赢"的叙事是 C2 立意的核心。

## 2. Semantic Probabilistic Layers（SPL；Ahmed et al., NeurIPS 2022；arXiv 2206.00426；代码 github.com/KareemYousrii/SPL）
- 方法：约束电路（SDD，用 PySDD 编译）× 条件概率电路，**端到端**用精确最大似然训练。层级分类任务以 HMCNN 为对照，指标是 exact match 和 Hamming 分数。
- **核实了代码**：层级分类实验只用了 8 个 **FunCat（_FUN，树形层级）** 数据集 + 4 个 "others"（diatoms、enron、imclef07a/d）。仓库里最大的 SDD 只有 109 KB。正文里"56 到 4130 类"引用的是 C-HMCNN 的数据范围，**SPL 没有跑任何 GO（DAG）数据集**。
- **差异**：
  - C2 是对**冻结的**预测器做后处理，并用矩匹配作起点；SPL 要重新训练网络。
  - C2 跑在**数千个术语的 GO DAG** 上（GO cc / GO mf 词表用 d4 精确编译）。
  - C2 报告的是 Fmax / AP 和校准；SPL 报告的是 exact match。
  - SPL 仍是最接近的方法学前作，论文必须正面比较。可能需要一个 "SPL 风格、端到端从头学"的对照（待定）。

## 3. 把描述逻辑本体编译成概率电路（arXiv 2601.14894，2026-01，审稿中）
- 把 ALCI 本体编译成 SDD 后用于 SPL / semantic loss。实验只用随机生成的本体，概念数 ≤ 100；作者明确说 CNF 规模随本体大小指数增长，是可编译本体的"concrete limit"。
- **对我们的意义**：真实大本体（GO）上的精确概率推理仍是公开难题。这支持把 GO bp 规模的推理当作计算贡献，第 (d) 项要证明的正是这一点。

## 4. 其他（只看了摘要或二手描述，未逐一核实）
- C-HMCNN（Giunchiglia & Lukasiewicz, NeurIPS 2020）：靠 max 约束层保证一致性，不是概率联合模型。
- HEMDAG / ISO-TPR（Valentini 组）：后处理，真路径规则 + 保序回归。
- FALCON（2013）：把 GO 当作离散贝叶斯网络来消解矛盾。
- 层级保形预测（arXiv 2508.13288）：给集合覆盖保证，不是联合后验。

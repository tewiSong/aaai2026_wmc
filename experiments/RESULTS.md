## P0.4　确定性画像

- **运行**：冒烟测试由 Claude 在登录节点完成（输出已删除）；正式运行为 Slurm 数组作业 22919437_0–4（small），2026-10-16 21:19–21:22。GO bp 用时 3 min，ChEBI 1 min 52 s，峰值内存约 1.4 GB。
- **产物**：`results/p0_4_determinism_<本体>_min-fill.json`（汇总 + 每个 bag 一行）
- **口径**：对 P0.3 min-fill 分解中大小 ≥16 的全部 bag，计算其上合法赋值数，也就是诱导偏序的 up-set 数。下界取 Dilworth 宽度（一个反链本身就给出 2^w 个 up-set），上界取链覆盖界 ∏(|C_i|+1)；能在预算内精确计数的给精确值。下表都取 log2。

| 本体 | bag 数 | 最大 bag 大小 | 最大 bag 合法状态（下界 / 上界或精确） | 全部 bag 表项总数：dense / 稀疏 | 精确计数比例 | 精确计数 bag 节省位数中位数 |
|---|---|---|---|---|---|---|
| GO cc | 0（宽度 11，无 ≥16 的 bag） | — | — | — | — | — |
| GO mf | 49 | 39 | 23 / 27.7（精确） | 2^40.7 / **2^29.6** | 100% | 6.7 |
| UBERON | 163 | 46 | 31 / 35.8（精确） | 2^47.9 / **2^37.9** | 100% | 6.8 |
| GO bp | 1,796 | 340 | **174** / 259 | 2^340.6 / 2^176–2^261 | 63% | 7.9 |
| ChEBI | 1,126 | 739 | **483** / 623 | 2^740.5 / 2^485–2^624 | 71% | 4.3 |

GO bp 有 122 个 bag 的合法状态下界超过 2^100，ChEBI 有 272 个。

**结论**

1. **确定性只带来常数级节省。** 精确计数的 bag 上，合法状态比 2^|S| 少的位数中位数只有 4–8 位，不会改变问题的规模量级。
2. **GO mf 可以精确求解。** 稀疏表项总数约 2^29.6（约 8 亿个），一个普通节点的内存就够。这意味着 GO mf 能拿到**全图精确真值**，可用来检验近似方法（P2a）。注意：GO mf 正是原稿报告 JT OOM、分解确实生效（6,519 个模块）的本体。
3. **UBERON 处于边缘。** 稀疏表项总数约 2^37.9（约 2.6×10^11 个，按 float64 约 2 TB），最大 bag 2^35（约 290 GB）。按当前这个分解不现实；是否可解取决于更好的树分解或 d4 这类编译方法（P1）。
4. **GO bp 和 ChEBI 在这个分解下没有精确解的希望。** 一个 bag 内就有 174（GO bp）和 483（ChEBI）个两两不可比的术语，合法状态至少 2^174 和 2^483。原稿"需要近似"的前提在这两个本体上成立。
5. **局限**：下界只对这个 min-fill 分解成立，不是问题本身的下界。其他分解或不基于树分解的方法（DPLL 加组件缓存、知识编译）可能更好，需要 P1 实测。

**对论文立意和方法设计的影响（重要）**

1. **规模主张收窄**：GO mf 可以精确求解，原稿"GO mf 上整体精确推理 OOM"的证据来自弱 baseline，不能再作为"需要本方法"的证据。本方法的必要性只在 GO bp / ChEBI（也许还有 UBERON）上成立。
2. **"这种分解下无法精确"不是要攻克的问题**：让 GO bp / ChEBI 可精确求解等于另写一篇精确算法论文，问题本身是 #P-complete，结构下界也很大。要做的只是用 P1（d4、更好的树分解）确认困难是固有的、不是 min-fill 的假象。确认后，这个困难本身就成为论文的动机证据。
3. **方法设计必须利用权重**：逻辑约束留下的状态太多（至少 2^174 / 2^483），TT 等低秩表示若有效，只能是因为分数分布让后验集中。原稿把 TT 当作结构性压缩，这个论证要换掉；新方法应显式按权重压缩，并给出误差保证。
4. **新出现的风险**：原稿自己的 GO cc 数据显示，真实分数下 BP 与精确解几乎一致。如果真实分数下后验普遍容易，"精确或高精度"的价值会被质疑。这比 P1 求解器对照更根本，因此新增 P1.0 难度诊断。
5. **GO mf 的精确真值是新稿的关键资产**：分解在 GO mf 上确实生效，又能拿到全图真值，可以直接回答审稿人 c36U 的核心质疑（大规模下精度如何）。

**对计划的影响**

- 结果分化，正是计划里 A/B 两条路线同时出现的情形：GO mf（可能还有 UBERON）走精确路线并提供真值；GO bp、ChEBI 需要近似路线（B）。
- **计划 §4 理论 2（用合法状态数给 TT rank 定上界）在 GO bp / ChEBI 上帮不上忙**：逻辑约束本身留下的状态太多。这两个本体上的可压缩性只能来自**分数分布**：真实预测器给绝大多数术语的分数接近 0，后验质量高度集中。近似路线的创新点应放在"按权重感知的压缩 + 误差保证"上，而不是只靠逻辑结构。需要新增一个诊断：在真实或接近真实的分数下，看后验质量集中在多少个状态上。
- P1 的重点：(a) d4 等能否解出 UBERON，甚至 GO bp；(b) 现成求解器在 GO bp / ChEBI 上是否失败；(c) 用稀疏精确消元给出 GO mf 的全图真值。

4. **方法设计不变，并得到加强**：P1.2 的"冷集剪枝 + 活跃核心精确求解"是主干。核心大小由中间分数个数决定，GO bp 一半蛋白有 ≥ 100 个中间分数，所以核心可能达到上千项，d4 超时的情形不会罕见。这正是计划 §8.4 截断分隔因子和后续近似部分需要发力的地方。
5. **新增一个建模层面的贡献点**：raw 分数实验揭示了乘积条件化语义对违反层级的预测器的行为，是之前分析都没注意到的问题，可以作为讨论或附加实验写进论文。

## 更正：Codex 对 P1.2 的独立复核（2026-10-19），Claude 逐项核实后的结论

复核报告：`../journal_comparison/Codex_P1.2独立复核与AIJ判断_2026-10-19.md`。以下各项都由 Claude 用原始 JSON 和重新运行核实过。

**统计口径（全部成立，以此为准）**

- 100 个蛋白是"50 个中间分数最多的 + 50 个随机"，不是随机样本，两组必须分开报告：

| GO bp prop | 随机组 | 中间分数最多组 |
|---|---|---|
| 得到证书 | **48 / 50** | 45 / 50 |
| 核心大小中位数（成功样本） | 292 | 713 |
| 核心求解时间中位数 | **0.25 s** | 14.6 s |

| 区间外术语数：中位 / 均值 | 224 / 251 | 624 / 624 |

- 0.01 是概率的**绝对误差一个百分点**，并且是每个蛋白所有术语中的最大值。它不是相对误差，也不是预测准确率。此前汇报中"平均 224 个术语"有误，224 是中位数。

**最重要的更正：证书主要来自 DiamondScore 中的精确零值**

- GO bp prop 的全部 93 个成功样本中，剪枝阈值都是 1e-9，**核心大小恰好等于非零分数的术语数**。被"剪掉"的就是原本为 0、被截断抬到 1e-9 的术语。
- 原因：prop 分数把训练注释传播到祖先，非零支持天然是祖先闭包，零集天然向下封闭。对精确零值，确定性消元（单元传播）本来就能无误差地删掉它们。
- 因此 P1.2 实际证明的是："**对具有祖先闭包稀疏支持的同源转移分数，在支持集上用 d4 精确求解，可以为大多数蛋白给出完整 GO 的全部边缘。**" 它**没有**证明"真实后验普遍集中在小核心"，也没有证明剪枝证书本身有方法价值。此前"原稿的全图不确定场景不会出现"的说法撤回。
- 需要补的基线：把零分数作为单元子句直接交给 d4 的全图求解（很可能与当前管线等价）。

**BP 停止阈值**

- GO mf raw 的 P24387 是例外（可证误差 0.028）。把消息停止阈值从 1e-9 收紧到 1e-13 后，误差消失，属于过早停止。此前"raw 下 BP 全部一致"的写法不准确。

- `loopy_bp` 的默认阈值已改为 1e-13。后续正式对比要同时报告消息残差和边缘变化的稳健性。

**撤回的推断**

- "合法状态多，所以低秩只能来自权重、不能来自结构"：**推断错误，撤回。** 乘积分布有 2^m 个支持状态，TT rank 却只有 1。P0.4 只排除了按当前消元序显式枚举的做法。
- "命题 C 正面回答了 rank 8 是否够用"：**撤回。** 截断后的项数上界为 Σ_{j≤k} C(|M|, j)，可能很大，而且决定误差界的是整个模块的总几率 Λ。命题 C 给出的是一种有界的新表示，并没有解释旧方法 rank 8 的充分性。还缺：包含空模式的互斥完备编码、恢复被消去术语边缘所需的逐模式统计、全局误差预算的分配。
- raw 分数的退化：它是"未传播注释 + 乘积条件化"的结果，不能推广到用祖先标签训练的神经分类器，也不作为贡献点。
- "证书"指剪枝的解析误差界。核心电路仍是浮点求值，没有外向舍入，措辞上不称为"数值认证"。

## P4.0　下游：精确条件化是否改善真实预测？（作业 22974188，Claude 提交，2026-10-20）

- 数据：DeepGOPlus 1.0.6 CNN 分数，留出测试蛋白中在该命名空间有标签的部分（GO cc 2,912 个，GO mf 2,129 个）；GO cc / GO mf 词表理论；对蛋白做 1,000 次配对 bootstrap。脚本 `scripts/p4_0_downstream_conditioning_deepgoplus_cc_mf.py`。

| | GO cc Fmax | GO cc AUPR | GO cc ECE | GO mf Fmax | GO mf AUPR | GO mf ECE |
|---|---|---|---|---|---|---|
| 原始 CNN 分数 | 0.6891 | 0.6420 | 0.0037 | 0.5697 | 0.5100 | 0.0057 |
| **max-closure** | **0.6919** | **0.6428** | **0.0032** | **0.5749** | **0.5149** | **0.0052** |
| 精确条件化（WMC） | 0.6770 | 0.6108 | 0.0085 | 0.5427 | 0.4482 | 0.0097 |
| BP | 0.6767 | 0.6080 | 0.0086 | 0.5419 | 0.4448 | 0.0097 |

精确条件化减去其他方法的差值（95% bootstrap 区间）：

- **对原始分数**：GO cc Fmax [−0.014, −0.010]，AUPR [−0.034, −0.028]；GO mf Fmax [−0.032, −0.022]，AUPR [−0.068, −0.055]。Brier 和 ECE 也显著变差。
- **对 max-closure**：GO cc Fmax [−0.017, −0.012]；GO mf Fmax [−0.037, −0.027]。
- **对 BP**：Fmax 好 0.0004–0.0008，AUPR 好约 0.003。显著，但数值很小。

**机制诊断（Claude，登录节点）**

- 违反层级的边上，分数大多很小（均值约 0.02），它们不是主要原因。
- 条件化平均来说会抬高真实标签（GO cc +0.028，GO mf +0.013）、压低负例，但造成**大幅下降**的主要是真实标签：GO mf 有 3,209 个真实标签下降超过 0.1，而只有 870 个负例上升超过 0.1。这些被大幅压低的术语里，约一半有一个分数更低的祖先（基线是 24%）。另一半是中等分数的术语（约 0.22），祖先分数相近（约 0.24）。
- **解释**：对一个按标签边缘训练的预测器，深层术语的分数已经包含了祖先的信息；独立乘积语义又把祖先的不确定性当作额外的独立证据乘进去，深层术语因此被系统地压低。这与原稿批评路径式传播时所说的"证据重复计算"是同一类错误，这次出在建模语义上，而不是推理算法上。
- **试过一个朴素修复，失败**：把分数换成局部条件 q_t = p_t / 父节点分数后再条件化，GO cc / GO mf 的 Fmax 降到 0.06–0.13。原因是字面量权重无法表达"父关时子必关、父开时子以 q_t 开"的 Bayesian 网络语义（需要成对因子）。正确的局部条件语义需要另外编码，是一个研究问题，没有继续。

**撤回的解释与论证**

- "原因已证明是证据重复计算"：撤回为"合理的模型失配解释"。已确认的事实只有一个：**正确的标签边缘一般不是条件乘积模型的正确字面量参数。** 例如单边 C ⇒ A，边缘 P(A)=0.6、P(C)=0.3（本身满足层级），直接当权重条件化后变成 0.682 / 0.205。
- "朴素修复失败说明字面量权重表达不了局部条件模型"：**错误。** 在树上可以重参数化为一元权重：λ_i = q_i/(1−q_i) · ∏_{孩子 j}(1−q_j)。上例取 p_A′ = 3/7、p_C′ = 0.5，即可准确恢复 0.6 / 0.3（Claude 已手算核实）。多父 DAG 用成熟的 BN→WMC 编码即可，不构成新贡献。朴素修复的失败本来就不能否定正确的模型；其脚本和原始数值也没有保存。
- "方向 B 需要反复调用 WMC"：**错误。** 只有蕴含约束时，可实现的边缘集合恰好是 {0 ≤ μ ≤ 1, μ_c ≤ μ_p}（order polytope，Stanley 1986；构造：Y_i = 1[U ≤ μ_i]，U 是均匀随机数）。"最接近的一致边缘"就是保序回归 / 凸投影，**不需要 WMC**。只有在需要联合分布、联合查询或证据条件化时，WMC 才可能必要。
- **直接相关的前人工作**：Obozinski et al. 2008（Genome Biology），"Consistent probabilistic outputs for protein function prediction"。它已比较启发式、贝叶斯网络、KL 投影与保序回归，并报告多种协调方法会损害预测、保序回归较稳健。原稿的参考文献里就有这篇，方向 B 与它直接重叠。
- "原稿表 4 的提升来自更弱的预测器"：撤回。旧数据无法溯源，不同评测之间不可比，不为它指定原因。
- "推理失去应用价值"：收窄为"这个蛋白后处理用途没有显示出收益"。
- "GO bp 编译是生死关卡"：收窄。编译成败只是一个配置、一个预算下的实证，要和电路大小、摊销成本、使用场景一起判断。

**对论文立意的影响**

- **原稿的应用叙事**（条件化后处理改善蛋白功能预测）被两种分数（CNN、融合）在两个命名空间上反证，必须撤回。
- **"一致性修正"这个问题**已有成熟、更简单的解法（保序回归，Obozinski 2008），而且不需要 WMC。论文不能以它作为 WMC 的应用。
- **WMC 在这条线上仍可能必要的场景，只剩真正需要条件联合分布的任务**：联合查询，或证据条件化（例如已知部分实验注释时，更新其他术语的概率）。这些场景需要先定义一个合理的联合模型，并与"保序回归 + 简单规则"等基线比较，目前没有任何证据。
- **AIJ 的方法论文论据目前很弱**：推理层面的结果真实，但缺少一个 WMC 条件后验是正确语义、并且现有方法不够用的应用。

**结论**

1. **原始分数在各深度上与标签频率接近**（整体 ECE 0.003–0.005），可以视为近似校准的边缘概率。
2. **条件化在浅层抬高、在深层压低，而且压低程度随深度增加**：深度 5 被压到约 1/3，深度 9 约 1/28，深层阳性的分数几乎减半。浅层（深度 1–2）原本略被低估，条件化后反而更接近标签频率。
3. **单边恒等式**：对 c ⇒ a，分数分别为 c、a 时，P_T(a) = a / (1 − c(1 − a)) ≥ a，P_T(c) = a·c / (1 − c(1 − a)) ≤ c，只有 a = 1 或 c = 0 时取等号。也就是说，**即使输入恰好是正确的边缘，条件化也一定把父项抬高、把子项压低**。在祖先链上，深层术语必须要求所有祖先都为真，压低会逐层叠加。
4. Fmax 和 micro AP 都主要取决于具体的深层术语能否被排在前面，所以深层阳性被系统性压低，指标就下降；ECE 翻倍也与校准被深度方向性地破坏一致。
5. 这比之前"约一半大幅下降有更低祖先"的计数更直接地支持"边缘预测器 + 独立乘积语义 → 深度方向的系统偏差"这一解释。它仍是观察性证据：可控的链 / 树合成实验，以及校准、先验等其他因素的分离，留作后续机制实验（计划 §7.9 第 2 条）。

用户指出：理论上模型族能表示任意一致边缘，实验里 C 却连简单校准都不如，Claude 没有分析原因就建议换方向。诊断如下（`scripts/p4_4_diagnose_C_parameterisation.py`，`results/p4_4_C_parameterisation_go_mf_cnn.json`，GO mf / CNN，100 个蛋白）：

1. **模型族的表达能力得到确认**：对每个蛋白做矩匹配（目标是略向内部平移的保序回归边缘），求出 θ*，用 d4 电路精确计算。达到目标的最大误差中位数为 8.5e-5，个别蛋白未完全收敛（最大 0.03）。
2. **所需参数与 C 的形式相差很远**：θ* − logit(s) 随深度系统性增大，深度 1 为 −0.7，深度 2–7 依次为 +3.2、+4.6、+6.5、+6.9、+7.2、+7.9（对数几率单位），同一深度内的标准差为 2–3.5。也就是说，深层术语的权重要放大约 e⁶–e⁸ 倍，而且放大多少取决于该蛋白其他术语的分数。这正是 P4.2 中深度压低现象在参数空间里的对应，理论与实测一致。
3. **C 的形式表达不了 θ\***：C 设 θ_i = a_d·logit(s_i) + b_d，用这种按深度仿射的形式拟合 θ*，R² 只有 0.19，诱导出的边缘与目标的最大误差中位数达 0.98。即使加上父项 / 子项分数特征，R² 也只到 0.58。
4. **结论**：P4.3 的 C 无法表示"保持原分数"或"保序回归结果"，**与它所比较的基线不是嵌套关系**。它的失败说明的是 C 这个参数化不对，而不是"学习式约束模型"这一类方法无效。P4.3 的"按判据停止"结论**撤回**；P4.3 的数值作为"错误参数化"的结果保留。

**修正后的设计 C2**（`ModelC2`，见 `scripts/learned_constrained.py`）：对每个蛋白，

θ_i = θ\*_i(保序回归边缘) + w_{d,0} + w_{d,1}·logit(s_i) + w_{d,2}·logit(iso_i)，

其中 w 按深度共享、初值为 0。w = 0 时模型恰好等于保序回归目标，所以 C2 嵌套了保序回归；训练只会在此基础上调整。

**C2 冒烟测试**（GO mf / CNN，拟合 60 个 / 评估 60 个蛋白，只优化 60 步且未收敛；样本极小，不作结论）：

## 更正 5：C2 实现中的数值错误（Codex P4.4–P4.6 复核，2026-10-21，Claude 已复现并修复）

复核报告：`../journal_comparison/Codex_P4.4至P4.6_C2独立复核_2026-10-21.md`。

- **错误**：`learned_constrained.log_partition` 先把 p = σ(θ) 截断到 [1e-12, 1−1e-12] 再交给电路，然后又加上**未截断**的 Σ softplus(θ)。当 |θ| > 约 27 时，目标函数与梯度不一致。Claude 复现：单边、θ = (−40, 40)，真实 log Z = 0.6931，旧代码返回 13.0621。实际实验中有参数触发了这个问题，所以 L-BFGS 显示的"收敛"不能证明训练正确，矩匹配的个别大误差（0.06–0.13）也可能源于此。
- **修复**：`Circuit.marginals_theta` 直接从 log-odds 计算，log p = −softplus(−θ)，log(1−p) = −softplus(θ)，不做截断；`log_partition` 改用它。新自检 `scripts/p4_5_selftest_stable_log_partition.py`：200 个随机 DAG、θ ~ N(0, 25²)，log Z 误差 2.8e-14、边缘误差 1.4e-14。原有的引擎自检和 C 自检重跑全部通过。修复后的冒烟测试中，矩匹配最大误差从 0.019 降到 8e-6。
- **处理**：v1 的结果（`*_v1_unstable_logZ.json`）和 θ\* 缓存保留以便溯源，**不再作为结论依据**。P4.5 与 P4.6 用修复后的代码重跑：作业 23044088 和 23044090，后者依赖前者成功完成。
- **P4.6 v2 新增两个对照**：
  - (i) θ\* 作为特征的独立 logistic 回归 + 保序：用来区分"整个分数向量的参数变换"与"约束下的联合预测"；
  - (ii) 全分数向量的前 32 个主成分作为特征的独立 logistic 回归 + 保序：一个也能利用所有术语分数的非 WMC 基线。

**收窄的表述（接受 Codex 意见）**

- "严格嵌套"改为"**近似嵌套**"：w = 0 的起点是向内部平移（ε = 1e-3）后的保序回归，少数蛋白的矩匹配还不完全精确。

## P4.7a–d　(b) C2 是否需要精确推理？BP / Bethe 的诊断（Claude，2026-10-21）

脚本：`scripts/p4_7a_bethe_vs_exact_moment_matching_diagnostic.py`、`p4_7b_bethe_robustness_to_interior_shift.py`、`p4_7c_bethe_on_untied_targets.py`、`p4_7d_bp_at_exact_theta_star.py`。结果在 `results/p4_7[a-d]_*.json`。新增的推理组件（`loopy_bp_theta`、`moment_match_bethe`、`enforce_order_exact` 等）由自检 `scripts/p4_7_selftest_c2_bp_variant.py` 验证：树上 Bethe 闭式解与精确矩匹配相差 8e-6，Adam 训练器达到与 L-BFGS 相同的 NLL。

1. **BP 做矩匹配**：
   - 外层不动点迭代（每步都让 BP 完全收敛）太慢，冒烟测试 10 分钟没有完成；
   - 单循环方案在树上精确，但在 GO mf 上不收敛（信念误差 1.0）。

## 更正 6：P4.7 的 BP 对照有实现缺陷（Codex P4.7 复核，2026-10-22，Claude 已复现并修复）

复核报告：`../journal_comparison/Codex_P4.7_BP对照独立复核_2026-10-22.md`。

- **缺陷**：`loopy_bp_theta` 在概率域里做阻尼和收敛判断。近乎确定性的消息里极小的分量变化在概率域里看不见，但它们决定了 log-odds，于是 BP 会**错误地宣布收敛**，还会走到错误的不动点。Claude 复现 Codex 的反例：C ⇒ A，θ_A = −40、θ_C = 40，精确边缘是 (0.5, 0.5)，旧 BP 输出 (7.3e-8, 0.99999993) 并报告"已收敛"。
- **修复**：新增 `loopy_bp_logodds`，每条消息是一个标量 log 比值：子到父 = softplus(子的 cavity log-odds)，父到子 = −softplus(−父的 cavity log-odds)；阻尼和停止残差都在 log 比值上。自检 `scripts/p4_8_selftest_logodds_bp.py` 通过：两节点反例得到 (0.5, 0.5)；30 棵强权重树（θ ~ N(0, 15²)）上与精确值相差 1.2e-14；中等权重的有环图上与旧 BP 的不动点一致。

| CNN：成功数 / 中位时间 | 20/20，0.17 s | 19/20，2.3 s（失败的核有 1,394 项） | 7/20，38 s | 1/20 |

  GO cc / GO mf 在所有 τ 上都在 0.14 s 以内。GO bp 的编译墙大约在 1,000 项：超过以后多数超时，最小的失败核只有 769 项。P6.2 显示 τ = 0.01 已经足够，而 GO bp 在 τ = 0.01 时大多可解，正好处在可行边界内，热核特别大的蛋白要靠自适应提高 τ（P6.3）。
- **但核外质量 Λ 很大**：DeepGOPlus 给几千个术语都输出小而非零的概率。GO bp 即使把一半词表放进热核，Λ 仍约为 1。所以剪枝证书 1 − ∏(1 − p) 和 Prop C 的截断界在这里都不紧，靠"核外可以忽略"来保证误差这条路走不通。

### P6.1 混合推理：热核精确 + 核外 log-odds BP（自检，登录节点）
- 热核取全部术语时退化为精确推理（自检通过）。在随机 14 节点 DAG 上，近似热核的最大误差为 0.11。用钉住信念的方法做核外矩匹配，得到的不动点有 5/90 不稳定，迭代复现不出来。
- 在 GO mf 的 3 个蛋白、精确 θ\* 处：混合推理的边缘误差为 0.02–0.15，随热核变大下降得很慢。核外矩匹配 9/9 不收敛。
- **原因**：保序回归把很多父子术语并成相同的值，精确 θ\* 因此让核外术语与父术语近乎确定性地耦合（核外 θ 可以很大）。BP 在这种耦合下有多个不动点、误差大，与 P4.7 v2 的结论一致。核外概率小并不等于 BP 在核外准确。
- **结论**：这种混合方案不能作为 C2 在 GO bp 上的推理后端。

  - 原稿基于全局误差界的模块化 / 截断方法（Prop C）不是必要条件，最多作为可选的证书。

### P6.4 C2 输给逐术语 Platt 的原因诊断（作业 23148482，探索性划分）
**问题**：C2 在 CNN 输入下被逐术语 Platt 追平或超过：GO cc CNN 上 P5 锁定确认里 AP 差 [−0.011, −0.004]，P4.5 探索性划分里 [−0.008, −0.001]；GO bp CNN 上不显著。融合输入和 GO mf 上 C2 都胜。
**假设**：C2 的残差按深度共享参数（D×3 个），修不了逐术语的系统性失准；逐术语 Platt 每个术语有 2 个参数。
**变体**（都用完整 d4 精确推理，与 P4.5 同一划分）：
- C2 + 逐术语偏置 b_i；
- C2 + 逐术语仿射 b_i + a_i·logit(s_i)；
- 以逐术语 Platt 的输出作为输入的 C2：拟合半部的输入用 5 折交叉拟合，w = 0 时退化为逐术语 Platt + 保序回归。

逐术语参数的岭系数 λ ∈ {1e-3, 1e-2, 0.1, 1} 在拟合半部内部 80/20 划分上按联合 NLL 选定，评估半部只用于最终指标。另报告逐术语偏差：各术语"平均预测 − 标签频率"的绝对值的平均。
自检：三种参数化的梯度通过有限差分检查（相对误差 ≤ 4e-5），80 个蛋白的冒烟测试跑通。

- **假设成立。** C2 在 CNN 输入上的缺口来自残差按深度共享参数，无法修正逐术语的系统性失准，而不是联合（WMC）建模本身的问题。加上带岭正则的逐术语仿射残差后：
  - C2 在 4/4 设置的 AP 上都显著优于逐术语 Platt；
  - 在 3/4 设置上不差于或优于原 C2；
  - 代价是在 GO mf 融合上略逊于原 C2（AP −0.003，Fmax −0.006）。
- **"先逐术语校准、再进 C2"不可取。** 这个变体对逐术语 Platt 只多出 +0.002 到 +0.004 的 AP，在 GO mf 上为零，在融合输入上比原 C2 显著更差（GO mf 融合 AP −0.019）。逐项独立拟合的 Platt 参数（每个术语只看自己的标签）会损失 C2 能利用的跨术语信息；用联合 NLL 和岭正则一起拟合的逐术语参数则没有这个问题。这一点是推断，没有直接检验。
- **ECE 没有改善**：C2+仿射的 ECE 仍高于逐术语 Platt，例如 GO cc CNN 0.0008 vs 0.0005。
- **选择性注意**：这些变体是看到 P5 的结果之后才设计的，所以 P5 的时间划分测试集不能再当作对它们的独立确认。干净的确认只能来自从未评估过的数据，即 GO bp 时间划分。


### P6.5 GO bp 热核 C2 的截断敏感性（作业 23148739，已完成）

**解读**：
- **融合输入**：在固定 w 下，结果对截断程度不敏感。AP 变化 −0.0005，比相对保序回归的增益 +0.020 小 40 倍。
- **CNN 输入**：固定 w 时，扩大核会严重破坏预测。原因是 w 是在核 A 上拟合的，核 B 新纳入的低 μ\*（0.001–0.01）项在核 A 中从未出现在模型里。深度共享残差 w_{d,1}·l + w_{d,2}·m 在这些项上外推，CNN 输入下 l 和 m 偏离大，就把它们推高了。这一机制是推断，没有逐项检验。
- **含义**：热核 C2 的参数与 τ 绑定，不是某个"全本体 C2"的截断近似。论文只能把它写成"在每个蛋白的热核上定义并拟合的模型族"。训练和测试必须用同一核规则，P7 满足这一点。
- **没有回答的问题**：在更大核上重新拟合 w，表现是否不变（P6.2 在 GO cc / mf 上按 τ 重拟合后与完整 C2 等价）。这个检验在 GO bp 上要再做一次全量矩匹配，代价约 1–2 天。
- Codex 在 `journal_comparison/Codex_P6.4诊断与新版主模型复核_2026-10-25.md` 中事先指出过：P6.5 固定旧 w，不检验新版仿射模型，也不能给出"与截断无关"的保证。这一点成立。

# AAAI 2026 Overleaf bundle

Self-contained upload package for *Modular Weighted Model Counting for Neuro-Symbolic Inference over Large Ontologies*.

## Files

| File | Purpose |
|------|---------|
| `main.tex` | Paper source (anonymous AAAI-26 submission) |
| `aaai2026.sty` | Official AAAI 2026 style file |
| `aaai2026.bst` | Official AAAI 2026 bibliography style |
| `references.bib` | Bibliography database |
| `fig_cc_error_vs_indegree.png` | Figure 1 |

## Overleaf setup

1. Create a new blank project on Overleaf.
2. Upload **all files in this folder** (drag-and-drop the whole directory contents).
3. Set the main document to `main.tex` (Menu → Main document).
4. Recompile. Overleaf runs `pdflatex` + `bibtex` automatically.

The `[submission]` option in `aaai2026.sty` enables anonymous review mode.
